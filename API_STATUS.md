# Seller API: состояние реализации

Подключение экспериментальное. Официальные схемы, текущие права без Premium и ответы реального магазина не проверены. Запросы к https://docs.ozon.ru/api/seller/ и https://api-seller.ozon.ru отклонены сетевым прокси этой облачной среды. Это ограничение среды, не установленный отказ Ozon и не доказательство необходимости Premium.

## Что реализовано

- Клиент только с чтением через фиксированный HTTPS-адрес api-seller.ozon.ru. Перенаправления запрещены; проверка TLS не отключается.
- Протокол финансов `/v3/finance/transaction/list`, FBO `/v2/posting/fbo/list`, FBS `/v3/posting/fbs/list`. Контракты требуют сверки с актуальной официальной документацией до объявления готовности.
- Пагинация; контроль количества финансовых строк и стабильности страниц; отказ при дублирующихся ID или неизвестной структуре. Повторы сетевых ошибок, 429 и 5xx ограничены четырьмя попытками; Retry-After ограничен 30 секундами. 401/403 не повторяются вслепую и не трактуются как требование Premium.
- Даты разбиваются на окна до 28 дней. Даты интерфейса интерпретируются как Москва (UTC+3), границы запросов — UTC. Семантика дат и ограничения каждого метода требуют проверки по действующей документации. Окна — консервативное решение клиента, не утверждение о текущем лимите Ozon.
- Полный снимок финансов выбранного периода сохраняется одним коммитом после успешной загрузки всех страниц и заказов. При неполной загрузке прежние данные и дата успеха сохраняются. Повторные ID обновляются; исчезнувшие из полного финансового снимка строки периода удаляются. Отправления сохраняют последние полученные статусы; отсутствие отправления в новом запросе не удаляет историю.
- Сохраняются суммы, типы финансовых операций, комиссии/услуги в полученных полях, состав отправлений, артикулы, SKU, количество и статусы. Имена покупателей, адреса и прочие лишние поля отбрасываются.
- Одна база привязывается к одному Client ID после первого успешного обновления API. Переключение магазина в той же базе блокируется. Исходный Excel не содержит проверенной привязки к Client ID — пользователь должен выбрать тот же магазин.
- Ключ вводится в локальной форме, поле пароля очищается после сохранения подключения. В Windows доступно шифрование DPAPI для текущего пользователя и атомарная запись зашифрованного файла. В других ОС нет хранения в открытом виде: ключ остаётся в памяти сеанса. Родной DPAPI проверяется отдельным Windows-тестом в workflow; в Linux тест пропущен.
- Кнопка обновления и добровольное расписание при открытой вкладке. Автообновление по умолчанию выключено; просматривает последние 90 дней. Для более старых корректировок нужен расширенный ручной период. Последний полный успешный запрос отображается отдельно от импорта Excel. После закрытия приложения фонового Windows-сервиса нет.

## Что пока не готово

API-данные находятся в отдельных таблицах api_finance/api_postings для сверки. Они **не меняют бухгалтерский ledger Excel и не пересчитывают прибыль**. Нельзя просто добавить API-суммы к Excel: это создаст повторный учёт. Нужно проверить реальные структуры, знаки, состав amount, начисления баллов и сопоставление товаров/количеств, затем реализовать согласованный переход источника с проверкой сумм.

Не реализованы отдельные методы возвратов/компенсаций и Performance API. Финансовые операции с такими типами сохранятся, если они придут в финансовом ответе; это не означает полноту информации о физических возвратах и рекламе. Отдельная рекламная статистика, её права и доступность ещё не установлены. Не подтверждены актуальные сроки хранения истории, максимальные периоды запросов, лимиты частоты и ограничения Premium. Не подтверждается окончательность прибыли или полнота отчёта Ozon.

## Что разблокирует проверку

В настройках облачной среды нужно **добавить**, сохранив существующие разрешения, домены:

- docs.ozon.ru — официальная документация Seller API;
- api-seller.ozon.ru — сервер Seller API;
- seller.ozon.ru — официальные инструкции подключения и налоговые пояснения.

Доступного инструмента изменения конфигурации среды нет, поэтому эти разрешения не сохранены автоматически. После изменения нужно повторить фактическую проверку доступа; наличие домена в настройках ещё не доказывает успешное соединение. Ключи не присылайте в чат. Сначала требуется проверить документацию, затем выполнить пробный запрос через форму приложения с ключом только на чтение и сопоставить результат с известным Excel-периодом.

## Windows

Подготовленный workflow запускает общий набор тестов (включая DPAPI на Windows), собирает PyInstaller и проверяет старт EXE. Workflow не запускался и архив с проверенной Windows-программой пока отсутствует. Публичный архив исходников не содержит ключей, баз и реальных финансовых отчётов.

## Диагностика HTTP 404

Кнопка «Проверить методы API» выполняет три малых независимых запроса и показывает только метод и безопасный статус. Она не меняет финансовую базу. Ошибка HTTP теперь содержит точный путь метода. Ключи, тела ответов и реальные финансовые строки в диагностическую таблицу не включаются. Можно выбрать загрузку только финансов, чтобы ошибка метода отправлений не блокировала их сверку. Это не автоматический обход устаревшего метода и не подтверждение его актуальности.
