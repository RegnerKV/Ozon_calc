# Seller API: состояние реализации

Адреса и структуры запросов обновлены по двум опубликованным схемам за октябрь 2026 года. Источники, даты отключения прежних методов и точные контракты — в [API_MIGRATION.md](API_MIGRATION.md). Прямая официальная документация и сервер API недоступны из этой облачной среды; реальная проверка идёт в размещённом приложении пользователя.

Рабочие запросы клиента:

- POST /v1/finance/accrual/by-day — по одному дню, страницы last_id;
- POST /v1/finance/accrual/types — справочник названий начислений;
- POST /v3/posting/fbo/list — отправления FBO, страницы cursor;
- POST /v4/posting/fbs/list — отправления FBS, страницы cursor.

Старые finance v3/FBO v2/FBS v3 в запросах не используются. Диагностика делает четыре независимые пробы и показывает методы и безопасные ошибки без ключей/сырых ответов. Финансы можно загрузить отдельно от отправлений.

Полный финансовый снимок выбранного периода заменяется одной транзакцией после получения всех выбранных данных. Ошибка на любой странице оставляет прежние записи и дату успеха. Итог начисления берётся ровно один раз из total_amount; компоненты не складываются с итогом. Положительные/отрицательные значения сохраняются, валюта проверяется (RUB). Повтор ID, неверная дата и зацикливание курсора приводят к отказу от сохранения. Ответы API не пишутся в журнал. Покупательские имена и адреса не сохраняются.

Транспорт: HTTPS, фиксированный адрес api-seller.ozon.ru, без редиректов и без отключения TLS. Сетевые ошибки/429/5xx — до четырёх попыток; задержка до 30 секунд. 401/403/404/400 не повторяются автоматически. Расположение дат интерфейса — Москва; финансовый запрос использует календарный день. Отправления фильтруются по времени в UTC, с сохранением конца дня до микросекунд.

Одна база связывается с одним Client ID после первой успешной загрузки. Ключ вводится в приложении, после сохранения поле очищается. Windows DPAPI шифрует постоянное хранение для текущего пользователя, Linux использует только память сеанса. Реальный DPAPI проверяется Windows-тестом, в Linux он пропущен. Расписание добровольное и по умолчанию выключено; работает при открытой вкладке. Автоматически пересматриваются последние 90 дней, более старые даты выбираются вручную.

Ограничения: API-данные находятся в api_finance/api_postings для сверки и **пока не пересчитывают прибыль Excel**. Нельзя прибавлять их к Excel — это задвоит учёт. Не подтверждены реальные права ключа/доступ без Premium, успешная загрузка текущего магазина и итоговое совпадение со сверкой. Отдельные Performance API, физические возвраты, банковские выплаты и подтверждение окончательности прибыли не реализованы. Дневные финансовые начисления включают полученные финансовые возвраты/компенсации/рекламу, если они присутствуют в ответах, но не заменяют все специализированные отчёты.

Для прямой проверки документации в настройках облачной среды нужно добавить docs.ozon.ru, api-seller.ozon.ru, seller.ozon.ru, сохранив другие разрешения. Инструмента изменения этих настроек здесь нет. Ключи в чат не присылайте.
