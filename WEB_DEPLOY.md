# Открыть приложение по ссылке через Streamlit Community Cloud

В форме Deploy an app:

- Repository: RegnerKV/Ozon_calc
- Branch: main
- Main file path: app.py
- App URL: можно оставить предложенное значение.

В Advanced settings выберите Python 3.12. В поле Secrets добавьте строку:

```toml
app_password = "ЗАМЕНИТЕ_НА_СВОЙ_ПАРОЛЬ"
```

Придумайте отдельный новый пароль не короче 12 символов. Не используйте пароль GitHub или API-ключ Ozon. Не присылайте пароль в чат. Сохраните его у себя. Пароль вводится в Secrets сервиса, не в файлы GitHub.

После этого нажмите Deploy. После успешного запуска откройте ссылку и введите свой пароль. Если пароль не настроен, доступ к данным останется закрыт. Факт появления страницы входа не означает проверку облачного хранилища или API.

Приложение предназначено для одного владельца. Все сеансы, знающие пароль, работают с одной базой. Не передавайте пароль другим людям. Можно дополнительно ограничить видимость приложения средствами сервиса, если такая настройка доступна вашему аккаунту. Не включайте OZON_PROFIT_LOCAL=1 на сервере: эта настройка предназначена только для локального desktop launcher.

После входа откройте «Импорт отчётов Ozon» и загрузите исходные Excel. Исходники GitHub не содержат финансовую базу или исходные отчёты. Загружаемые в веб-версию данные обрабатываются на сервере Streamlit, а не только на вашем компьютере.

В Community Cloud локальные файлы могут потеряться при пересоздании сервера. Не считайте облачную SQLite надёжным постоянным хранилищем: сохраняйте базу через «Настройки → Подготовить резервную копию базы» и храните исходные Excel. Восстановление базы через интерфейс пока не реализовано; можно повторно загрузить исходники, но ручные изменения потребуют восстановления отдельно. Windows-версия сохраняет данные в личной папке компьютера и не имеет этого ограничения сервиса.

Подключение Seller API пока экспериментальное; загруженные API-данные не участвуют в прибыли. Начинайте с Excel. Ключи не помещайте в GitHub и не пересылайте в переписке. В Linux ключ существует только в текущем сеансе. Работа расписания требует открытого приложения.
