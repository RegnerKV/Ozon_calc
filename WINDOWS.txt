Ozon Profit — первая версия

1. Распакуйте ВЕСЬ архив в отдельную папку.
2. Дважды нажмите OzonProfit.exe. Откроется браузер с приложением.
3. Не закрывайте чёрное окно программы, пока работаете.
4. Чтобы завершить работу, закройте окно программы. Закрытие вкладки браузера само по себе программу не останавливает.

Устанавливать Python не нужно. Все данные сохраняются отдельно от папки программы:
%LOCALAPPDATA%\OzonProfit\profit.db
Перед резервным копированием базы закройте программу.

Начните с раздела «Как пользоваться».
Это предварительный расчёт на основе импортированных Excel, без подключения API.
Не считайте начисления прибылью или остатком денег. Проверяйте себестоимость, полноту отчётов и налоговую базу.

Программа не подписана цифровой подписью. Windows может показать предупреждение.
Используйте только собственную сборку из своего репозитория; не отключайте защиту Windows.
