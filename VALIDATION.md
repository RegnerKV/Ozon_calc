# Проверка первой версии

Проверено в текущей Linux-среде, Python 3.12.

- `python -m pytest -q`: **85 passed, 1 skipped**. Проверка расчётов Decimal, истории, оценочной стоимости, возвратов, ограничений восстановленного количества, повторного импорта, корректировок, атомарности и сохранения базы.
- Создание и чтение XLSX в памяти; распознавание исходных форматов Ozon, блоков себестоимости с упаковкой и предыдущей сверки.
- Автоимпорт с повторяющимися/пустыми ID, возврат удержанного эквайринга, сверка реализации, замена полного периода с удалением исчезнувших строк; отказ при пересечении с ручным импортом и неизвестном типе начисления.
- Проверки всех разделов Streamlit, добавления стоимости, импорта четырёх синтетических файлов через интерфейс, финансовых карточек и фильтра заказа.
- Предоставленные пользователем четыре исходных файла разобраны отдельно от публичных тестов. Реализация, количества и партнёрские выплаты совпали по всем артикулам. Итог начислений, себестоимость, налог и прибыль по прежней методике независимо воспроизведены и совпали с предыдущей сверкой после округления.
- Синий вариант «Наличника» подтверждён пользователем. Обе «Малины» сохранены как оценочная стоимость по «Рыбе».
- Интерфейс проверен с приватной базой предоставленных данных: обзор и справочник открываются без ошибок. Финансовый результат отображается корректно. Личные данные и сам файл сверки находятся вне исходников.
- Зависимости проверены `pip check`; исходники компилируются. `launcher.py` реально запускался: 127.0.0.1, динамический порт, HTTP 200 от страницы и health endpoint; процесс после проверки остановлен.

Ограничения: налоговая база из прежней сверки остаётся предварительной. Официальная статья Ozon недоступна из среды из-за сетевого запрета прокси (403). Добавлен экспериментальный API-клиент: пагинация, редактирование/удаление записей полного снимка, атомарность при ошибке, ограничение повторных попыток и проверка секретов тестируются на вымышленных ответах. Реальный контракт Ozon, доступ без Premium и включение API в прибыль пока не проверены. Предусмотрено добровольное расписание при открытом приложении. Подтверждение полноты периода и банковские выплаты не реализованы. Один тест DPAPI пропущен в Linux: требуется Windows. Расписание и реальная сеть на длительном запуске не проверялись. Сборка PyInstaller и запуск EXE на Windows не выполнялись: workflow подготовлен, релиз не опубликован.

Инструкции установки/старта сохранены в README. Инструмента сохранения install_script/start_skill в конфигурацию среды нет. Публикация среды и отправка исходников на GitHub не выполнялись.

Веб-режим: проверены закрытие доступа без настроенного пароля и с коротким паролем, отказ неверного пароля, вход и выход. До входа база данных не создаётся. Добавлены защищённый по умолчанию старт и получение согласованной резервной копии SQLite. Внешняя публикация на Streamlit пока не проверена.

Диагностика HTTP 404: проверены включение адреса метода в безопасную ошибку, независимые пробы трёх методов после отказа одного из них и финансовая загрузка без вызова отправлений. Реальный источник полученного пользователем 404 ещё не установлен: нужен результат проверки методов на стороне размещённого приложения.

Ответы API с ошибками: проверено безопасное извлечение code/message без полного тела ответа, скрытие отражённых Client ID/ключа и скрытие пояснений об авторизации. Удалён пустой необязательный status из запросов отправлений; положительный эффект на реальном Ozon не подтверждён. Корневая причина пользовательских 404/400 ещё не установлена; ожидается структурированное пояснение провайдера.
