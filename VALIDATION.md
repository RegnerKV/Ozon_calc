# Проверка приложения

Текущая среда Linux, Python 3.12: `python -m pytest -q` — **96 passed, 1 skipped**.

Проверено:

- Расчёты Decimal, история/оценочная себестоимость, возвраты, ограничение восстановленного количества, корректировки, повторный импорт, атомарность и сохранение SQLite.
- XLSX round-trip, оригинальные форматы Ozon, блоки «С упаковкой», сопоставление реализации с начислениями по артикулу и сравнение предыдущей сверки.
- Замена полного периода с удалением исчезнувших строк и запрет пересечения с ручным импортом.
- Все страницы Streamlit, импорт четырёх синтетических файлов через интерфейс, справочник, карточки результата, фильтр заказа, ввод и удаление сеансового ключа.
- Закрытый веб-режим по умолчанию: отсутствие/короткий пароль не открывают базу; неверный пароль отклоняется, вход/выход проверены.
- Новые API-пути по двум опубликованным схемам октября 2026: by-day/types, FBO v3, FBS v4. Старые адреса запрещены. Финансы запрашиваются по дням с last_id, отправления — с cursor; изменившаяся/циклическая страница отклоняется.
- Новые корневые JSON-ответы, денежные объекты RUB, проверка ID/даты/валюты/категории, отсутствие двойного сложения total_amount с его детализацией. Синтетические POSTING/ITEM/NON_ITEM/CONTAINER_FEES.
- Ошибки сети/HTTP, ограниченные повторы, редактирование/удаление снимка, сохранение прежних данных при позднем отказе метода, отдельная загрузка финансов и защита от смешивания магазинов.
- Безопасная диагностика четырёх методов и извлечение ограниченных code/message без ключей и полного тела ответа. Ответ с ошибкой/неизвестным конвертом даже при HTTP 200 не считается пустым успешным периодом.
- Структура файлов шифрованного хранилища проверяется синтетическим шифром; настоящий DPAPI-тест пропущен в Linux и требует Windows.

Отдельно от публичных тестов: предоставленные пользователем четыре файла разобраны; суммы, количества, партнёрские выплаты по артикулам совпали. Прежний расчёт независимо воспроизведён с прежней налоговой базой. Пользователь подтвердил синий «Наличник»; обе «Малины» остаются оценочными. Приватная база и Excel со сверкой находятся вне репозитория. Обзор и справочник с приватной базой проверялись без ошибок.

Зависимости проходили pip check, исходники compileall. Локальный launcher запускался с 127.0.0.1/динамическим портом: страница и health отвечали HTTP 200. После проверки сервер остановлен.

Ограничения: после миграции ещё требуется успешный запрос с пользовательским ключом в размещённом приложении. Прямое чтение docs.ozon.ru блокируется прокси; источники и границы подтверждения описаны в API_MIGRATION.md. Доступ без Premium не подтверждён реальным запросом. API-данные пока не включены в прибыль. Налоговая база, полнота периода, банковские выплаты, длительная работа расписания и Windows-сборка не подтверждены этими тестами. Публичные исходники не содержат финансовых отчётов, баз, паролей и ключей.
